Grabz.it Thumbnail Generator for Formidable Forms

Plugin Overview

The Auto Thumbnail Generator for Formidable Forms plugin is a powerful tool designed to automatically generate thumbnails for Formidable Forms entries. Leveraging the GrabzIt API, this plugin streamlines the process of creating visually appealing thumbnails, making it easier to manage and showcase your forms.

Logs are triggered via email, ensuring the client stays informed about the plugin's operations and status. Special thanks to the GrabzIt development team for their support during the development process.

Features

Automated Thumbnail Generation: Automatically creates thumbnails for Formidable Forms entries.

GrabzIt API Integration: Utilizes the robust GrabzIt API for reliable and high-quality thumbnail generation.

Email Logs: Sends detailed logs of operations via email for monitoring and troubleshooting.

Customizable Settings: Adjust plugin configurations to suit your specific needs.

Seamless Integration: Works directly within the Formidable Forms framework for a smooth user experience.

Installation

Download the plugin zip file.

Log in to your WordPress admin dashboard.

Navigate to Plugins > Add New.

Click Upload Plugin and select the downloaded zip file.

Click Install Now and activate the plugin.

Configuration

Go to Settings > Auto Thumbnail Generator.

Enter your GrabzIt API credentials.

You can obtain these from the GrabzIt API Documentation.

Configure the email settings to specify the recipient for log emails.

Save changes and start generating thumbnails automatically for your Formidable Forms entries.

Usage

Create or edit a Formidable Form.

Submissions made to the form will automatically trigger thumbnail generation.

Generated thumbnails can be viewed or downloaded from the form entry details.

Log emails will be sent to the configured email address with updates and error reports (if any).

Requirements

WordPress 6 or higher

Formidable Forms Plugin

GrabzIt API key

PHP 7.4 or higher
